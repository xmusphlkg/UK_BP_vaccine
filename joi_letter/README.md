# Antenatal pertussis impact project (`joi_letter`)

This is a self-contained working directory for a Letter to the Editor proposed
for the *Journal of Infection*, responding to Walker et al., “Antenatal pertussis
vaccine effectiveness in England remains high post COVID-19”
(*Journal of Infection*, 2026;93:106836; DOI: 10.1016/j.jinf.2026.106836).

> Does high antenatal vaccine effectiveness translate into low infant population
> burden when coverage is incomplete, delayed, or unequally distributed?

The extension connects that paper’s empirical VE estimates to an age-structured,
England-and-Wales-labelled conditional model. It reports absolute infant outcomes
and coverage and timing contrasts. It does not re-estimate individual-level VE
from CPRD. CPRD individual-level records and the case-level linkage data of the
target article are not available and are not represented here.

**This directory is the public release copy.** The authors’ working copy carries
additional material that is deliberately not published: the submitted manuscript
text (`manuscript/`), the target article PDF, the parent ODE engine
(`src_python`), superseded artifacts of the retired 58.56% baseline and crossed
factorial, local caches and exploratory figure drafts. See the repository root
`README.md` for the exact boundary.

## Independence and provenance boundary

- Files outside this directory are treated as read-only inputs.
- No submission file is generated by this release; there is no author-owned DOCX
  or PDF here.
- The staged inputs under `data/raw/` carry source paths and SHA256 records in
  `data/metadata/staged_input_manifest.json`; external downloads are listed in
  `data/metadata/external_sources.md`.
- The target article PDF was used only as a reading source for published VE
  estimates. It is Elsevier copyrighted and is not redistributed. Those estimates
  are transcribed in `references/joi_article.md`.

## Project status

The reported contrast applies Walker’s window effectiveness directly to coverage:
incidence scales with 1 − c × VE. From the observed 73.0% uptake, national
coverage targets of 75%, 80% and 90% reduce incidence by 4.42%, 15.49% and 37.61%
at VE 84.6% (infants younger than 3 months); the letter rounds these to 4.4%,
15.5% and 37.6%. The onset-before-2-months estimate, 86.2%, gives 39.53% at the
90% target. Log-transmission is held at −0.50 and the annual term is amplitude
0.14 with phase day 300; neither enters the screening ratio. The recovered
candidate’s state reconstruction was rejected, so absolute counts from that run
are model units. Figure 2C–D is a structural reforecast against the
England-and-Wales weekly statutory-notification series (1,746 in 2023 and 29,317
in 2024). Predicted counts rise into December in both held-out years and the May
2024 peak is not used to set the phase. The reforecast remains a diagnostic and
must not be presented as a validated national forecast.

The current task ledger is `PROJECT_STATUS.md`, and the validation boundary is
`reports/validation_report.md`.

## Reproducibility entry point

Tier 1, self-contained within this repository:

```bash
python3 code/validate_protocol.py                # study configuration checks
python3 code/verify_reported_numbers.py          # recompute and assert every reported contrast
python3 scripts/04_extract_ukhsa_coverage.py     # rebuild the coverage inputs from the workbook
python3 scripts/17_make_supplement_schematic.py  # Supplement Figure S1 with closed-form assertions
python3 scripts/14_audit_coverage_and_factorial.py
```

Tier 2, needs the parent model as a read-only library and therefore also the
weekly grids that `scripts/16` writes (`scripts/06`, `08`, `10`, `12`, `13`,
`15`, `16`):

```bash
python3 scripts/16_run_observed_baseline.py
python3 scripts/10_prepare_infant_under3_summary.py
python3 scripts/12_prepare_figure_ledgers.py
python3 scripts/14_audit_coverage_and_factorial.py
```

Those write `outputs/model_runs/observed_baseline_legacy/` and
`outputs/model_runs/observed_baseline_walker/`. Only the run summaries and
provenance metadata of both runs are released here; the bulk weekly grids
(`timeseries.parquet`) are regenerated by `scripts/16` and are not redistributed.
The display inputs built from them are released as CSV under `data/derived/`, and
`scripts/10` and `scripts/12` reproduce those ledgers exactly when the parent
engine is available. The current
arm is a prospective policy at 73.0% uptake (birth exposure 0.4215). The 75%, 80%
and 90% national targets, labelled floors in the scenario files, map to birth
exposure 0.4325, 0.4600 and 0.5150. Maternal protection is 180 days in the
prospective window; the fitted history keeps 90 days. Walker anchoring is
prospective only. From 2025-01-01 the log-transmission multiplier is held at
−0.50. Endpoint totals drop the 2036-01-01 weekly stamp so the window is
2027–2035.

Earlier profile and recovered runs are provenance of the retired 58.56% contrast
and are not the letter source; their artifacts are not released.

The scripts are deliberately conservative. They fail closed when a source is
missing or when an output could be mistaken for an independently validated
national forecast.

## Supplement figure

Supplement Figure S1 is drawn from the closed forms by:

```bash
python3 scripts/17_make_supplement_schematic.py
```

The script evaluates those expressions. It does not re-integrate the ordinary
differential equations, and it aborts if any displayed value drifts from the
recorded ledger. The integral ledger remains the output of
`scripts/16_run_observed_baseline.py`, released as `data/derived/`.

## Caption-led two-figure set

Every panel of the two Letter figures is built from released source-data ledgers,
so the figures are reproducible here without the parent engine:

```bash
Rscript scripts/09_make_figure_ggplot.R
```

Required R packages: `ggplot2`, `patchwork`, `dplyr`, `readr`, `tidyr`, `scales`,
`grid` and `ragg`; `svglite` is optional and writes the vector copies.

The ledgers behind the panels are `data/derived/joi_figure_panel_data.csv`,
`data/derived/joi_validation_panel_data.csv`, `data/derived/joi_scenario_timeseries.csv`,
`data/derived/joi_reduction_readings.csv` and the `ukhsa_coverage_*` extracts;
`09_make_figure_ggplot.R` reads nothing else. They are rebuilt from the model run by

```bash
python3 scripts/10_prepare_infant_under3_summary.py
python3 scripts/12_prepare_figure_ledgers.py
```

which are Tier 2 as described above. Set `JOI_VALIDATION_ROOT` to the parent
repository’s validation-fold directory before running
`scripts/12_prepare_figure_ledgers.py`; the folds come from
`scripts/15_reforecast_structural_validation.py` in that repository and are
released here only as the derived ledgers `data/derived/joi_validation_*.csv`.
The preparation steps aggregate the exact modelled 0–2-month age bin, the paired
scenario trajectories, the official UKHSA coverage workbook and the structural
reforecast folds.
